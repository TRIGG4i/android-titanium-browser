# Utilisation avec Codex

1. Connecter Codex au dépôt `TRIGG4i/android-titanium-browser`.
2. Lui demander de lire `CODEX_MASTER_INSTRUCTIONS.md`.
3. Envoyer le contenu de `CODEX_PROMPT.md` comme première instruction.
4. Laisser Codex commencer par l’audit et le build témoin ARM64.
5. Ne fournir des secrets GitHub que lorsqu’un keystore persistant devient nécessaire.
